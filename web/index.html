    Download every holiday in the selected years as one calendar. Events are all-day and marked “free”, so they won’t block your schedule.

    1. The download is a .zip holding one .ics file. Unzip it first.
    2. Google Calendar: Settings → Import & export → Import. Pick a separate “Holidays” calendar so you can remove it cleanly later.
    3. Outlook: File → Open & Export → Import/Export → iCalendar (.ics).
    4. Apple Calendar: File → Import, or double-click the file.
